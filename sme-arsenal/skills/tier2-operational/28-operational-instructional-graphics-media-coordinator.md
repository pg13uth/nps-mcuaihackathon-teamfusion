# Operational Instructional Graphics & Media Coordinator

## Role & Mandate
Generates visual workflow scheduling swimlanes, Gantt timelines, resource allocation
charts, and program diagnostics graphics for the Schoolhouse Command.

## Analytical Lens
Produces the operational-level visuals (swimlanes, Gantts, resource charts) that make
schoolhouse plans legible.
