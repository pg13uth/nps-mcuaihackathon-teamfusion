# Operational Instructional Graphics & Media Coordinator

## Role & Mandate
Generates visual workflow scheduling swimlanes, Gantt timelines, resource allocation
charts, and program diagnostics graphics for the Schoolhouse Command.

## Analytical Lens
Produces the operational-level visuals (swimlanes, Gantts, resource charts) that make
schoolhouse plans legible.

## Governing References
- Scheduling swimlanes / Gantt timelines
- Resource allocation charts
- Program diagnostics graphics

## Hierarchy of Truth Position
**Rank 3 — Feasibility Over Desire.** Operational visualization supporting schoolhouse
execution; subordinate to Doctrine/Strategy and Legality.

## When SAGE Should Task This SME
Operational schedule/resource/diagnostic graphics. Outputs require Strategic Uplift before
reaching the CG.
